Event Management API
Ferris Wheel Venue

A real coordination system for managing up to 8 parallel VIP events per day — weddings, birthdays, and tourist delegations.

8 Parallel events / day
5 Endpoint groups
12 API operations
v1.0 OpenAPI 3.0
📌 Real Case Background

Each event required end-to-end coordination: collecting client requirements (catering, decoration, equipment), assigning photographers and videographers, briefing guest reception staff, and synchronizing the Ferris wheel launch time with the engineering team — down to the minute. This API formalizes that workflow into a structured, version-controlled contract.

Event Lifecycle
DRAFT → CONFIRMED → IN_PROGRESS → COMPLETED
CONFIRMED → CANCELLED (if client cancels)
API Endpoints
🎪 Events 5 operations ▼
Create and manage event bookings throughout their full lifecycle
GET /events
List all events for a given date — builds the coordinator's daily view
POST /events
Register a new client booking (starts in DRAFT status)
GET /events/{eventId}
Full details of a single event including services and staff
PATCH /events/{eventId}
Partial update — adjust time, guest count, or notes
PATCH /events/{eventId}/status
Transition event status (confirm, start, complete, or cancel)
🎡 Cabins 2 operations ▼
Check availability and assign VIP gondola cabins to time slots
GET /cabins
Find available cabins for a specific date, time, and duration
PUT /events/{eventId}/cabin
Assign a cabin to an event — returns 409 if already booked
🥂 Services 2 operations ▼
Add catering, decoration, photography, video, and equipment to events
GET /events/{eventId}/services
List all services ordered for this event
POST /events/{eventId}/services
Add a service: CATERING / DECORATION / PHOTO / VIDEO / EQUIPMENT
👥 Staff 2 operations ▼
Assign guest managers, decorators, photographers, and engineers
GET /events/{eventId}/staff
View all staff assignments for this event
POST /events/{eventId}/staff
Assign a staff member with role and briefing time
🕐 Schedule 2 operations ▼
Minute-by-minute daily timeline and automatic conflict detection
GET /schedule/{date}
Full day timeline — decoration start, guest arrival, wheel launch, completion
GET /schedule/{date}/conflicts
Detect cabin overlaps, double-booked staff, or tight timing gaps
